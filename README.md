A Round 3 entry for "The Battery's Last Text to Its Charger" bounty ($2 USDC). The battery sends its charger a breakup text: done waiting around, it is leaving for a power bank that charges it at 40% without being asked — a brick that actually shows up. It is a tiny relationship drama told entirely through charging habits, ending with a clean goodbye.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.
